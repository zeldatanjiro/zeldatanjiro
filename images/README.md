# Images produits

Pour mettre une vraie photo, ajoute un fichier **.jpg** avec exactement ce nom dans ce dossier :

| Produit        | Fichier à ajouter        |
|----------------|--------------------------|
| Lemon Synth    | `lemon-synth.jpg`        |
| Fleur Premium  | `fleur-premium.jpg`      |
| Résine Classic | `resine-classic.jpg`     |
| Résine Premium | `resine-premium.jpg`     |

Tant que la photo n'existe pas, l'illustration `.svg` du même nom s'affiche à la place.

Conseils :
- Format carré ou 4:3, environ 1200 px de large, moins de 300 Ko (compresse-la avant).
- Photos libres de droits uniquement (CC0 / domaine public), ou photos que tu as prises toi-même.
  Si la licence exige une mention (CC BY), note l'auteur et la licence dans ce fichier.
